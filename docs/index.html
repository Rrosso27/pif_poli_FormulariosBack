pif

Guía de instalación y puesta en marcha

Laravel PHP MySQL REST API
1
Clonar el repositorio

Clona el repositorio en tu máquina local con Git.

bash 
git clone https://github.com/Rrosso27/pif_poli_FormulariosBack.git
2
Crear la base de datos

Antes de continuar, crea una base de datos con el nombre:

sql 
pif_poli_formularios_back
Este nombre es opcional. Si decides cambiarlo, recuerda actualizarlo también en el archivo .env.
3
Crear el archivo .env

Crea una copia del archivo .env.example y renómbrala como .env.

bash 
cp .env.example .env
4
Instalar dependencias de Composer

Asegúrate de tener Composer instalado y ejecuta el siguiente comando para instalar las dependencias del proyecto.

bash 
composer install
5
Ejecutar las migraciones

Las migraciones gestionan la estructura de la base de datos y permiten versionar sus cambios. Ejecuta el siguiente comando para aplicarlas.

bash 
php artisan migrate
6
Ejecutar los seeders

Los seeders insertan datos iniciales en la base de datos —en este caso, una encuesta de ejemplo para facilitar la interacción con el sistema.

bash 
php artisan db:seed
7
Ejecutar el servicio 🚀

Verifica que todos los pasos anteriores se hayan completado correctamente y levanta el servidor de desarrollo.

bash 
php artisan serve
El servidor estará disponible por defecto en http://127.0.0.1:8000
